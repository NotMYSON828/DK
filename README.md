# DK

A tiny browser game built for the `DK` repository.

## Play locally

1. Open `index.html` in a browser.
2. Use `A/D` or `←/→` to move.
3. Jump with `W`, `↑`, or `Space`.
4. Collect 8 gems and reach the portal to win.
5. Press `R` to restart.

## Goal

`DK` is a short arcade platform challenge where you collect gems, avoid hazards, and reach the goal portal.
